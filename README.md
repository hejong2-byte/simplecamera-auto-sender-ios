# SimpleCamera 자동전송 ADD-ON

Simple Cam으로 촬영한 새 사진을 자동 전송하고, 사용자가 직접 선택한 사진·스크린샷·동영상을 기존 업무사진 수신기로 보내며, PC에서 보낸 모든 일반 파일을 iPhone 내부 또는 외장 USB에 저장하는 iOS 보조 앱입니다. 현재 버전은 0.3.0(빌드 11)입니다.

![SideStore 설치 QR](docs/install-qr.png)

[SideStore에서 설치하기](sidestore://install?url=https%3A%2F%2Fgithub.com%2Fhejong2-byte%2Fsimplecamera-auto-sender-ios%2Freleases%2Flatest%2Fdownload%2FSimpleCameraAutoSender.ipa)

## 동작 방식

- 새 사진의 원본 해상도가 `6048×8064` 또는 `8064×6048`인지 확인합니다.
- 카메라·렌즈 모델에 `iPhone` 표식이 있는 사진은 제외합니다.
- 단축어 자동화가 실행되면 즉시 첫 검색과 실제 PC 업로드를 시작합니다.
- 원본 저장이 아직 끝나지 않은 경우에만 0.5초 간격으로 최대 10초 동안 다시 확인하며, 전송을 마치면 바로 종료합니다.
- 앱 표시 이름과 `Software` 메타데이터는 판별에 사용하지 않습니다.
- 사진 수 제한은 없으며, 촬영 시각순으로 한 장씩 서버 응답까지 확인한 뒤 다음 사진을 전송합니다. 성공한 사진은 다시 보내지 않습니다.
- 첫 화면의 **자동전송 상태**에 현재 사진/전체 사진, 실제 전송 바이트 기준 프로그레스바와 퍼센트, 완료·실패 개수 및 오류 원인을 표시합니다.
- 실패한 사진은 앱에서 재시도할 수 있습니다.
- 인증값은 아이폰 Keychain에만 저장되고 저장소·IPA·QR에는 포함되지 않습니다.

## 직접 선택해서 전송

- 앱 첫 화면의 **사진 전송**, **스크린샷 전송**, **동영상 전송**에서 여러 항목을 한 번에 선택할 수 있습니다.
- 선택한 항목만 전송하며 보관함의 다른 파일은 검색하거나 보내지 않습니다.
- 기본 카메라 사진은 **사진 전송**에서 선택합니다. **스크린샷 전송**은 스크린샷 앨범만, **동영상 전송**은 동영상만 표시합니다.
- 준비·전송·재시도·서버 저장 확인 상태와 전송률, 전송 바이트, 완료/실패 개수를 실시간으로 표시합니다.
- 95MiB가 넘는 파일은 정확히 32MiB 단위(마지막 조각 제외)로 자동 분할해 R2에서 다시 조립하므로 일반적인 300~400MB 동영상도 전송할 수 있습니다.
- 전송 큐를 아이폰에 저장하므로 다른 앱으로 전환하거나 화면을 잠가도 iOS 백그라운드 전송이 계속되며, 앱이 다시 실행되면 남은 작업과 상태를 복원합니다.
- 수동 파일 한도는 2GiB이며 MOV, MP4, JPEG, PNG, HEIC, HEIF 원본을 지원합니다.

## PC 파일을 iPhone 또는 USB에 저장

- 첫 화면의 수동 전송 상태 아래에 있는 **PC 파일 수신**에서 iPhone을 한 번 등록하면 Windows 송신기에 입력할 6자리 수신 코드가 표시됩니다.
- 저장 위치는 **나의 iPhone**(기본값) 또는 **USB 직접 저장**으로 선택합니다. USB를 쓸 때는 Lightning-USB 어댑터와 USB 메모리를 연결하고 **USB 폴더 선택**으로 저장 폴더를 지정합니다.
- Windows 송신 화면의 **iPhone USB** 항목은 iPhone 내부 저장도 지원합니다. 수신 코드를 입력해 선택한 일반 파일을 보내며, 0바이트 파일도 지원합니다. 폴더나 묶음은 ZIP으로 보냅니다.
- **나의 iPhone**으로 받은 파일은 `파일 > 나의 iPhone > SimpleCamera 업무사진 전송 > 받은 파일`에 저장됩니다. 시작된 다운로드는 iOS가 백그라운드에서 이어갈 수 있지만, 앱을 열지 않은 채 새 PC 파일을 상시 발견하지는 않습니다.
- **USB 직접 저장**은 수신 화면이 전면에 있을 때 한 파일씩 진행합니다. USB가 없거나 사용할 수 없으면 **iPhone에 저장** 또는 **서버에 대기**를 선택합니다.
- iPhone에 보관한 파일은 앱의 저장 파일 목록에서 선택한 뒤 **선택 파일 USB로 복사**로 나중에 옮길 수 있습니다. USB 복사는 앱의 수신 화면을 전면에 둔 채 진행합니다.
- 파일 크기와 SHA-256 검증을 통과한 최종 파일만 완료 처리합니다. USB 복사 후 **원본 유지(권장)** 또는 **iPhone 원본 삭제**를 묻고, 삭제를 직접 선택한 파일만 다시 검증해 삭제합니다. 기존 파일은 덮어쓰지 않고 받은 파일을 자동으로 열거나 실행하지 않습니다.
- 진행률, 퍼센트, 바이트, 속도, 남은 시간과 검증 단계를 표시합니다. USB 직접 수신이 중단되면 검증된 8MiB 경계부터 이어받습니다.
- Wi-Fi 전용이 기본입니다. 설정에서 셀룰러 수신을 허용할 수 있습니다. 4GiB 초과 파일에는 exFAT USB와 전원 공급형 Lightning-USB 어댑터를 권장합니다. 서버 보관 기한은 기본 7일입니다.

## 설치 후 한 번만 설정

자세한 순서는 [설치 및 자동화 설정 안내](docs/install.md)를 따르세요. 앱의 **설정** 안에서 사진 접근, 인증, 자동 전송 시작과 자동화 안내를 순서대로 확인할 수 있습니다. SideStore 설치 앱은 SideStore의 일반적인 7일 갱신 대상입니다.

## 중요 제약

iOS는 일반 앱의 상시 백그라운드 실행을 허용하지 않습니다. 따라서 단축어의 개인용 자동화에서 `Simple Cam이 닫힐 때` 이 앱의 `새 SimpleCamera 사진 전송` 동작을 즉시 실행하도록 한 번 연결합니다. 동작이 시작되면 보조 앱이 자동으로 열려 실제 PC 업로드가 끝날 때까지 수행합니다. 사용자가 `지금 전송`을 누르거나 사진 검색·선택·반복 단축키를 추가할 필요는 없습니다.

수동 사진·동영상 전송과 이미 시작된 iPhone 로컬 다운로드는 앱 전환을 지원하지만, 앱 전환 화면에서 사용자가 이 앱을 위로 밀어 **강제 종료**하면 iOS가 백그라운드 작업을 취소할 수 있습니다. 저장된 진행 상태는 다음 실행 때 복구합니다. USB 직접 저장·복사는 수신 화면을 전면에 둔 채 사용해야 합니다. iOS 앱은 스스로 종료되지 않습니다. 실제 Lightning 어댑터·USB 메모리 인식과 전력 공급은 기기에서 확인해야 하며, 시뮬레이터 테스트가 이를 보증하지 않습니다.
