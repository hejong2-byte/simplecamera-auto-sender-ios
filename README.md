# SimpleCamera 자동전송 ADD-ON

Simple Cam으로 촬영한 새 사진을 자동 전송하고, 사용자가 직접 선택한 사진·스크린샷·동영상을 기존 업무사진 수신기로 보내며, PC에서 보낸 모든 일반 파일을 iPhone 내부 또는 외장 USB에 저장하는 iOS 보조 앱입니다. 현재 버전은 0.3.34(빌드 45)입니다.

0.3.34는 파일 앱에서 `열기`를 누른 직후 선택 상태가 사라져 전송이 시작되지 않거나 기본 폴더가 저장되지 않던 시트 종료 경쟁을 수정했습니다. 선택은 시트가 닫히기 전에 확정하고, 보안 접근은 iPhone 임시 복사가 끝날 때까지 유지합니다. PC에서 iPhone 대상으로 받은 JPG·PNG·HEIC·MOV·MP4는 일반 파일 원본을 보존하면서 사진 앱에도 추가하며, 사진 권한 오류는 원본 수신 성공과 구분해 표시합니다. 일반 파일 준비·SHA-256·PC 업로드 진행률과 `500GiB 미만` 수동 전송 지원은 그대로 유지합니다.

0.3.29는 ZIP 루트에 `SD_CARD_ROOT`와 JSON·TXT 같은 파일이 함께 있어도 `SD_CARD_ROOT` 폴더를 USB·SD카드에 만들지 않습니다. JSON·TXT는 루트에 유지하고 `SD_CARD_ROOT` 안의 실제 폴더와 파일만 저장장치 루트로 올립니다.

0.3.28은 중단된 USB 복사의 실제 남은 데이터를 다시 확인해 이어받고, ZIP 내용물을 USB 루트에 확정하던 중 앱이 중단된 경우 이미 완료된 루트 항목을 건너뛰어 나머지만 마무리합니다. 중단 기록은 원본 ZIP을 지우지 않고 별도 버튼으로 제거할 수 있습니다.

0.3.27은 iPhone에 저장된 ZIP을 USB·SD카드에 압축 해제해 복사할 때 ZIP 이름 폴더, `SD_CARD_ROOT`, `ROOT`처럼 내용물을 감싼 포장용 상위 폴더를 반복 제거합니다. 따라서 드라이브를 열면 `MAP`, `ASR_DB`, `_bin` 같은 실제 폴더가 루트에 바로 보입니다. 네비게이션에 필요한 ZIP 내부 폴더 구조는 그대로 보존합니다.

0.3.26은 USB 복사 중 UIKit의 제한된 백그라운드 실행 시간이 끝나면 작업을 안전하게 멈추고, 앱으로 돌아오는 즉시 같은 USB의 중단 지점부터 자동으로 이어 씁니다. 앱이 종료된 뒤에도 같은 원본과 같은 USB를 다시 선택하면 저장된 부분의 크기와 마지막 64KB를 확인한 후 남은 바이트만 복사합니다. ZIP은 완료된 압축 해제 결과와 이미 복사된 내부 파일을 재사용합니다. 사용자가 복사 취소를 누른 경우에만 이어받기용 임시파일을 정리하며 원본 ZIP은 유지합니다. iOS가 무제한 백그라운드 USB 복사를 보장하지는 않지만, 중단 때문에 처음부터 다시 복사할 필요는 없습니다.

0.3.24는 PC 수신 결과의 `확인·닫기`로 알림 기록만 지울 수 있습니다. 저장 파일·USB 복사본·전송 작업은 유지하고 새 오류는 다시 표시합니다. USB 복사 속도를 크게 표시하고 현재 복사 작업의 예상 남은 시간을 보여줍니다. 추정 시간에는 이후 파일과 ZIP 압축 해제 시간이 포함되지 않습니다.

USB 폴더 생성·쓰기·이름 변경에 외부 저장장치 파일 조정을 적용합니다. iPhone 저장 ZIP을 압축 해제해서 복사할 때 ZIP 이름, `SD_CARD_ROOT`, `ROOT` 포장 폴더를 USB·SD카드에 만들지 않고 그 내용물을 선택한 저장장치 루트에 바로 넣습니다. USB에 기존 최상위 이름이 겹치면 덮어쓰기나 이름 변경 없이 충돌을 알립니다. 복사 취소는 현재 파일 작업이 반환된 뒤 처리하며 원본을 보존합니다. `임시파일 정리`는 확인 후 앱이 생성한 압축 해제 임시폴더와 미완료 USB 복사본만 정리합니다. 분리된 저장장치는 다시 연결·선택해야 하며 파일시스템 손상을 복구하는 기능은 아닙니다. SD 전체 삭제 후 잔여 목록을 짧게 재확인하여 지연된 목록을 즉시 실패로 판정하지 않습니다. 실기기 리더기의 장시간 I/O 정체 해결 여부는 별도 확인이 필요합니다.

0.3.23은 iPhone에 저장된 파일의 USB 복사를 쓰기·닫기 오류와 크기 확인 후 완료 처리합니다. ZIP 압축 해제 시 CRC 손상 검사는 유지하고, 원본 ZIP 반복 SHA 검사와 USB 전체 재읽기는 기본 경로에서 제거했습니다. 복사 중 이미 읽은 데이터로 검증 기록을 만들며, USB 정밀 SHA 검증은 선택 파일의 별도 버튼으로 실행합니다. 선택 검증 실패 시에도 USB 복사본과 iPhone 원본은 삭제하지 않습니다. 임시 압축해제 파일은 정리하고 ZIP 원본은 복사 완료 후 사용자에게 묻고 삭제합니다. 파일마다 강제 동기화하지 않으므로 앱이 작업 종료를 표시하기 전에 USB를 분리하지 마세요. 기존 파일을 보존하려면 앱 삭제 없이 업데이트하세요.

0.3.21은 대용량 SHA 검증·USB 복사 중 임시 메모리 누적을 수정한 안정화 후보입니다. 진행 중인 수신에 저장 위치 선택창을 다시 띄우지 않으며, 이미 저장했거나 완료 통보를 기다리는 파일은 새 수신 목록에서 제외합니다. USB 접근 확인은 앱이 활성화된 동안 갱신합니다. 여러 새 파일은 홈의 **수신 대기 N개 · 저장 위치 선택**을 눌러 선택합니다. Mac에서 실제 SHA 코드의 8GiB 파일 검증과 메모리 사용을 시험하며, 실제 iPhone에서의 종료 해결 여부는 설치 후 별도 확인이 필요합니다. 앱을 삭제하지 말고 같은 앱 위에 업데이트하여 받은 파일과 재개 상태를 유지하세요.

## 동작 방식

- 새 사진의 원본 해상도가 `6048×8064` 또는 `8064×6048`인지 확인합니다.
- 카메라·렌즈 모델에 `iPhone` 표식이 있는 사진은 제외합니다.
- 단축어 자동화가 실행되면 즉시 첫 검색과 실제 PC 업로드를 시작합니다.
- 원본 저장이 아직 끝나지 않은 경우에만 0.5초 간격으로 최대 10초 동안 다시 확인하며, 전송을 마치면 바로 종료합니다.
- 앱 표시 이름과 `Software` 메타데이터는 판별에 사용하지 않습니다.
- 사진 수 제한은 없으며, 촬영 시각순으로 한 장씩 서버 응답까지 확인한 뒤 다음 사진을 전송합니다. 성공한 사진은 다시 보내지 않습니다.
- 첫 화면의 **자동전송 상태**에 현재 사진/전체 사진, 실제 전송 바이트 기준 프로그레스바와 퍼센트, 완료·실패 개수 및 오류 원인을 표시합니다.
- 실패한 사진은 다음 자동 실행에서 다시 시도합니다.
- 인증값은 아이폰 Keychain에만 저장되고 저장소·IPA·QR에는 포함되지 않습니다.

## 직접 선택해서 전송

- 앱 첫 화면의 **사진 전송**, **스크린샷 전송**, **동영상 전송**에서 여러 항목을 한 번에 선택할 수 있습니다.
- 선택한 항목만 전송하며 보관함의 다른 파일은 검색하거나 보내지 않습니다.
- 기본 카메라 사진은 **사진 전송**에서 선택합니다. **스크린샷 전송**은 스크린샷 앨범만, **동영상 전송**은 동영상만 표시합니다.
- 준비·전송·재시도·서버 저장 확인 상태와 전송률, 전송 바이트, 완료/실패 개수를 실시간으로 표시합니다.
- 95MiB가 넘는 파일은 기본 32MiB 단위로 나누고, 매우 큰 파일은 10,000조각을 넘지 않도록 조각 크기를 자동으로 키워 R2에서 다시 조립합니다. 조각은 한 번에 하나만 임시 생성해 전송 완료 즉시 삭제합니다.
- 전송 큐를 아이폰에 저장하므로 다른 앱으로 전환하거나 화면을 잠가도 iOS 백그라운드 전송이 계속되며, 앱이 다시 실행되면 남은 작업과 상태를 복원합니다.
- 수동 파일 한도는 500GiB 미만이며 MOV, MP4, JPEG, PNG, HEIC, HEIF 원본을 지원합니다.

## PC 파일을 iPhone 또는 USB에 저장

- 첫 화면의 수동 전송 상태 아래에 있는 **PC 파일 수신**에서 iPhone을 한 번 등록하면 Windows 송신기에 입력할 6자리 수신 코드가 표시됩니다.
- 서버에 받을 파일이 1개면 기존처럼 바로 저장 방식을 묻습니다. 2개 이상이면 **받을 파일 선택** 목록에서 하나 이상 고른 뒤 **선택 파일 먼저 받기**를 누릅니다. 목록이 열린 동안 서버를 반복 확인해도 실제 파일 목록이 바뀌지 않으면 선택창과 선택 상태를 교체하지 않습니다. 선택하지 않은 파일은 서버에 그대로 남아 다음 확인 때 다시 표시됩니다.
- 저장·검증·서버 수신 완료 처리가 끝나지 않은 파일은 안내를 닫거나 앱을 나가도 오류로 처리하지 않으며, 앱이 다시 활성화될 때 다시 안내합니다.
- 저장 위치는 **나의 iPhone**(기본값) 또는 **USB 직접 저장**으로 선택합니다. USB를 쓸 때는 Lightning-USB 어댑터와 USB 메모리를 연결하고 **USB 폴더 선택**으로 저장 폴더를 지정합니다.
- Windows 송신 화면의 **iPhone USB** 항목은 iPhone 내부 저장도 지원합니다. 수신 코드를 입력해 선택한 일반 파일을 보내며, 0바이트 파일도 지원합니다. 폴더나 묶음은 ZIP으로 보냅니다.
- **나의 iPhone**으로 받은 파일은 `파일 > 나의 iPhone > SimpleCamera 업무사진 전송 > 받은 파일`에 저장됩니다. 시작된 다운로드는 iOS가 백그라운드에서 이어갈 수 있지만, 앱을 열지 않은 채 새 PC 파일을 상시 발견하지는 않습니다.
- **USB 직접 저장**은 수신 화면이 전면에 있을 때 한 파일씩 진행합니다. USB가 없거나 사용할 수 없으면 **iPhone에 저장** 또는 **서버에 대기**를 선택합니다.
- PC에서 받은 묶음에 ZIP이 있으면 저장 위치보다 먼저 **압축을 해제하시겠습니까?**를 묻습니다. **ZIP 그대로 저장**은 iPhone 또는 USB를 이어서 선택하고, **압축 해제**는 ZIP을 iPhone 내부 임시공간에서 검증·해제한 뒤 USB의 숨김 임시 폴더에 복사합니다. 최종 폴더 전체를 다시 검증한 뒤에만 완료 처리하고 임시 ZIP과 해제본을 삭제합니다.
- iPhone에 보관한 파일은 앱의 저장 파일 목록에서 선택한 뒤 **선택 파일 USB로 복사**로 나중에 옮길 수 있습니다. USB 복사는 앱의 수신 화면을 전면에 둔 채 진행합니다.
- 선택 파일에 ZIP이 있으면 **압축 해제해서 복사** 또는 **ZIP 그대로 복사**를 고릅니다. 압축 해제는 CRC 손상 검사 후 USB에 복사하며, 두 방식 모두 쓰기·닫기 오류와 파일 크기를 확인합니다. USB 전체 재읽기 SHA 검증은 별도 버튼으로 선택 실행합니다. 임시 해제본은 정리하고 iPhone 원본은 사용자가 별도 삭제를 확인하기 전까지 유지합니다.
- 손상·암호화 ZIP이나 USB 밖으로 빠지는 경로·심볼릭 링크가 든 ZIP은 압축 해제해서 복사하지 않습니다. 같은 선택에 든 일반 파일은 선택한 ZIP 방식과 무관하게 원본 그대로 복사합니다.
- PC에서 iPhone으로 수신할 때는 파일 크기와 SHA-256을 확인합니다. iPhone 저장 파일의 USB 복사 후에는 **원본 유지(권장)** 또는 **iPhone 원본 삭제**를 묻고, 직접 삭제를 선택한 원본이 변경되지 않았는지 확인합니다. 기존 파일은 덮어쓰지 않고 받은 파일을 자동으로 열거나 실행하지 않습니다.
- 진행률, 퍼센트, 바이트, 속도, 남은 시간과 검증 단계를 표시합니다. USB 직접 수신이 중단되면 검증된 8MiB 경계부터 이어받습니다.
- Wi-Fi 전용이 기본입니다. 설정에서 셀룰러 수신을 허용할 수 있습니다. 4GiB 초과 파일에는 exFAT USB와 전원 공급형 Lightning-USB 어댑터를 권장합니다. 서버 보관 기한은 기본 7일입니다.
- **설정 → SD/USB 저장장치 관리**에는 선택한 저장장치 폴더와 파일시스템을 참고 정보로 표시합니다. **선택한 저장장치 내용 전체 삭제**는 삭제 전 파일·폴더 수와 용량을 다시 보여 주고 확인받은 뒤 선택한 폴더의 내용만 지웁니다. 선택한 폴더 자체와 iPhone 원본은 유지되며, 카드 전체를 비우려면 카드의 최상위 폴더를 선택해야 합니다. 파일시스템을 포맷하거나 변경하지 않습니다.

자세한 순서는 [설치 및 자동화 설정 안내](docs/install.md)를 따르세요. 앱의 **설정** 안에서 사진 접근, 인증, 자동 전송 시작과 자동화 안내를 순서대로 확인할 수 있습니다. SideStore 설치 앱은 SideStore의 일반적인 7일 갱신 대상입니다.

## 중요 제약

iOS는 일반 앱의 상시 백그라운드 실행을 허용하지 않습니다. 따라서 단축어의 개인용 자동화에서 `Simple Cam이 닫힐 때` 이 앱의 `새 SimpleCamera 사진 전송` 동작을 즉시 실행하도록 한 번 연결합니다. 동작이 시작되면 보조 앱이 자동으로 열려 실제 PC 업로드가 끝날 때까지 수행합니다. 사용자가 `지금 전송`을 누르거나 사진 검색·선택·반복 단축키를 추가할 필요는 없습니다.

수동 사진·동영상 전송과 이미 시작된 iPhone 로컬 다운로드는 앱 전환을 지원하지만, 앱 전환 화면에서 사용자가 이 앱을 위로 밀어 **강제 종료**하면 iOS가 백그라운드 작업을 취소할 수 있습니다. 저장된 진행 상태는 다음 실행 때 복구합니다. USB 직접 저장·복사는 수신 화면을 전면에 둔 채 사용해야 합니다. iOS 앱은 스스로 종료되지 않습니다. 실제 Lightning 어댑터·USB 메모리 인식과 전력 공급은 기기에서 확인해야 하며, 시뮬레이터 테스트가 이를 보증하지 않습니다.

업데이트나 중단으로 내부 작업 장부가 손상된 경우 앱은 해당 메타데이터만 `.corrupt-...` 파일로 격리하고 안전한 빈 상태로 실행합니다. `받은 파일` 폴더의 원본과 USB·서버 파일은 삭제하지 않습니다. 자동 사진 장부가 복구된 경우 과거 사진의 일괄 재전송을 막기 위해 자동전송은 꺼진 상태가 되므로 설정에서 **이 시점부터 자동 전송**을 다시 한 번 누릅니다.
