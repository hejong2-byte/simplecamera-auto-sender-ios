# 설치 및 자동화 설정

## 1. SideStore로 설치

1. 저장소의 QR을 아이폰 카메라로 스캔합니다.
2. SideStore가 열리면 `SimpleCamera 업무사진 전송`을 설치합니다.
3. SideStore에서 평소처럼 7일 이내에 갱신합니다.

## 2. 앱 최초 설정

앱을 열고 **설정**을 누른 뒤 화면의 1~3번을 순서대로 진행합니다.

1. **사진 전체 접근 허용**을 누르고 전체 접근을 허용합니다.
2. 기존 PC 수신기에서 사용하던 전송 인증값을 **전송 인증 설정**에 그대로 입력하고 저장합니다.
3. **이 시점부터 자동 전송**을 누릅니다. 이 버튼을 누르기 전 사진은 전송하지 않습니다.

인증값은 아이폰 Keychain에만 저장됩니다. GitHub 저장소, IPA, QR 코드에는 들어 있지 않습니다.

## 3. 개인용 자동화 한 번 만들기

1. 아이폰에서 **단축어** 앱을 엽니다.
2. 아래의 **자동화**를 누르고 새 개인용 자동화를 만듭니다.
3. **앱**을 선택합니다.
4. 앱으로 **Simple Cam**을 선택합니다.
5. 조건은 **닫힐 때**만 선택합니다.
6. 실행 동작으로 **새 SimpleCamera 사진 전송**을 검색해 추가합니다.
7. **즉시 실행**을 선택하고 실행 전 묻기는 끕니다.

이 자동화에는 `사진 찾기`, `최근 사진 가져오기`, `각 항목 반복`, `URL 콘텐츠 가져오기`를 추가하지 않습니다.

## 4. 사용

Simple Cam으로 한 장 또는 여러 장을 촬영하고 앱을 닫으면 보조 앱이 자동으로 열리고 새 SimpleCamera 사진을 모두 찾아 PC 전송 완료까지 수행합니다. 별도 버튼은 누르지 않습니다. 아이폰 기본 카메라 사진과 스크린샷은 전송하지 않습니다.

자동 사진 수에는 제한이 없으며 촬영 시각순으로 한 장씩 안정적으로 전송합니다. 첫 화면의 **자동전송 상태**에서 현재 사진/전체 사진, 실제 전송 바이트 기준 프로그레스바와 퍼센트, 완료·실패 개수와 서버·네트워크·인증·원본 오류를 확인할 수 있습니다.

**사진 조건 확인 중**의 숫자는 아직 전송 대상으로 확정하지 않은 검사 대상입니다. 실제 전송 수와 따로 표시하며, 해당 사진이 없으면 **전송할 새 사진 없음**으로 표시합니다. 판별 조건은 기존과 동일하게 **6048×8064 또는 8064×6048**이고 촬영 기기·렌즈 정보에 **iPhone** 표시가 없어야 합니다. 이 조건만으로 촬영 앱의 출처를 완전히 증명하는 것은 아닙니다.

원본을 읽지 못했거나 전송이 중단된 사진은 다음 자동실행에서 다시 시도합니다. 전송 완료로 기록된 사진은 다시 올리지 않으며 수동 전송의 완료 이벤트가 자동 사진 검사를 새로 시작하지 않습니다. 자동 사진 전송은 단축어가 보조 앱을 열어 진행하는 방식으로, 앱을 강제 종료한 상태에서 계속 실행된다고 보장하지 않습니다.

### 사진·스크린샷·동영상 직접 전송

1. 앱 첫 화면에서 **사진 전송**, **스크린샷 전송** 또는 **동영상 전송**을 누릅니다.
2. Apple 시스템 선택창에서 보낼 항목을 여러 개 선택합니다.
3. 완료하면 선택한 항목만 PC로 전송됩니다.

**사진 전송**에는 아이폰 기본 카메라 사진을 포함한 이미지가 표시됩니다. **스크린샷 전송**에는 스크린샷만, **동영상 전송**에는 동영상만 표시됩니다. 선택하지 않은 항목은 전송하지 않습니다.

화면에는 준비·전송·재시도·서버 저장 확인 단계와 프로그래스 바, 퍼센트, 전송 바이트, 완료/실패 개수가 표시됩니다. 95MiB가 넘는 파일은 기본 32MiB 단위로 나누며, 매우 큰 파일은 서버의 10,000조각 제한을 넘지 않도록 조각 크기를 자동 조정합니다. 파일당 최대 크기는 500GiB 미만입니다. 조각은 한 번에 하나만 임시 생성하고 전송 완료 즉시 삭제합니다.

전송을 시작한 뒤 다른 앱을 사용하거나 화면을 잠가도 iOS 백그라운드 전송이 계속됩니다. 전송 상태는 아이폰에 저장되어 앱이 다시 실행되면 남은 작업을 복원합니다. 다만 앱 전환 화면에서 앱을 위로 밀어 강제 종료하면 iOS가 전송을 취소하므로, 앱을 다시 열어 이어서 처리해야 합니다. 앱이 전송 후 스스로 종료되지는 않습니다.

### 파일 전송

1. 앱 첫 화면에서 **파일 전송**을 누릅니다.
2. 기본 폴더를 미리 지정하지 않았어도 Apple 파일 선택창이 곧바로 파일 선택 모드로 열립니다. 문서·사진 등 보낼 파일을 하나 이상 선택합니다.
3. 자주 쓰는 폴더가 있다면 **설정 → 파일 전송 기본 폴더**에서 지정할 수 있습니다. 이 설정은 파일 선택창의 시작 위치만 정하며, 폴더 자체를 전송하지 않습니다.

선택한 파일만 PC로 전송하고 원본은 그대로 유지합니다. 큰 파일의 분할 및 백그라운드 전송 방식은 사진·스크린샷·동영상 직접 전송과 같습니다.

### 텍스트 송수신

1. 첫 화면의 **텍스트 송수신**을 엽니다.
2. 상대 기기의 6자리 코드를 입력하고 보낼 내용을 작성한 뒤 **전송**을 누릅니다. 앞뒤 공백, 줄바꿈, 탭, 한글과 이모지를 그대로 보존합니다.
3. 자주 쓰는 코드는 입력칸 옆 **저장**을 눌러 `행정망 PC`, `아이폰`처럼 알아보기 쉬운 이름으로 최대 10개까지 저장합니다. 저장된 이름과 6자리 코드가 함께 표시되며, 항목을 누르면 받는 코드에 적용됩니다. 항목을 길게 누르면 이름 변경과 바로가기 삭제를 할 수 있습니다.
4. 수신한 텍스트는 최신순으로 표시됩니다. 기록을 짧게 누르면 상세 화면이 열리고, 길게 누르면 **전체 복사**, **TXT로 저장**, **공유**, **삭제** 메뉴가 바로 표시됩니다. 전송 실패 항목은 상세 화면에서 같은 내용으로 다시 시도할 수 있습니다.

텍스트는 1건당 UTF-8 기준 최대 1MiB입니다. 작성 중인 내용, 마지막으로 선택한 수신코드, 저장 코드 바로가기와 송수신 기록은 앱 안에 저장되어 재실행 후에도 복원됩니다. 바로가기를 삭제해도 송수신 기록과 작성 중인 내용은 삭제하지 않습니다. 수신 내용은 로컬 저장이 끝난 뒤에만 서버 수신 완료 처리하며, 앱을 열면 즉시 확인한 뒤 전면에 있는 동안 약 5초마다 다시 확인합니다. 앱이 닫힌 상태의 푸시 알림이나 상시 백그라운드 텍스트 수신은 지원하지 않습니다.

## 5. PC에서 보낸 파일을 iPhone 또는 USB에 저장

### iPhone 최초 1회 설정

1. 앱 첫 화면의 수동 전송 상태 아래에서 **PC 파일 수신**을 엽니다.
2. **이 iPhone 등록**을 누릅니다. 등록 뒤 표시되는 6자리 수신 코드를 Windows PC에 입력합니다.
3. 새 파일마다 도착 안내에서 **iPhone에 저장** 또는 **USB에 저장**을 선택합니다. 선택 전에는 다운로드하지 않습니다.
4. USB를 쓸 때만 Lightning-USB 어댑터를 연결하고 **USB 폴더 선택**으로 USB 메모리 안의 폴더를 지정합니다. 전력이 부족하면 전원 공급형 어댑터를 사용합니다.
5. 기본값은 Wi-Fi 전용입니다. 셀룰러로도 받을 때만 설정에서 **셀룰러 수신 허용**을 켭니다.

### Windows에서 보내기

1. `SimpleCamera 업무사진 수신기`의 **파일 보내기** 화면을 엽니다.
2. 받는 종류를 **iPhone USB**로 선택합니다. 이 항목은 iPhone 내부 저장도 지원하며 목적지는 iPhone 앱에서 선택합니다.
3. iPhone에 표시된 6자리 코드를 입력하고 확인된 기기명이 맞는지 확인합니다.
4. 사진·문서·영상·ZIP 등 보낼 파일을 추가하고 **보내기**를 누릅니다. 0바이트 파일도 지원하며 폴더나 묶음은 ZIP으로 보내면 됩니다.
5. PC가 서버 업로드를 마치면 상태는 **서버 업로드 완료 · iPhone 수신 대기**가 됩니다. 선택한 위치에서 크기·SHA-256 검증과 저장이 끝나야 **iPhone 저장 완료** 또는 **USB 저장 완료**로 바뀝니다.

### iPhone에서 받기

1. 앱을 열어두면 메인·설정·수신 화면에서 새 PC 파일 도착 안내가 표시됩니다. 목록 확인 응답이 끝난 뒤 1초 간격으로 다시 확인하므로 실제 알림 시간은 네트워크 응답 시간에 따라 달라집니다. 파일 선택창이나 기존 수신·삭제 확인창이 열려 있으면 닫힌 뒤 안내합니다.
2. 받을 파일이 1개면 기존처럼 그 파일의 저장 방식을 바로 묻습니다. 2개 이상이면 자동으로 선택창을 띄우지 않고 **수신 대기 N개 · 저장 위치 선택** 안내를 표시합니다. 이 안내를 눌러 **받을 파일 선택** 목록을 열고 파일명·크기·도착 시각·보관 만료 시각을 확인한 뒤 하나 이상 골라 **선택 파일 먼저 받기**를 누릅니다. 선택하지 않은 파일은 서버에 그대로 남습니다. 목록이 열린 동안 확인 결과가 같으면 선택 상태를 그대로 유지합니다. 앱을 다시 열 때도 여러 파일의 선택창은 이 안내를 눌러 엽니다.
3. 선택한 묶음에 ZIP이 있으면 저장 위치보다 먼저 **압축을 해제하시겠습니까?**가 표시됩니다. **압축 해제**, **ZIP 그대로 저장**, **나중에 받기** 중에서 선택합니다.
4. **압축 해제**를 선택하면 USB/SD를 최종 위치로 사용합니다. 원본 ZIP을 `iPhone 내부 임시공간`에 내려받아 크기와 SHA-256을 확인하고 안전하게 해제한 뒤, USB/SD의 숨김 임시 폴더로 한 파일씩 복사합니다. 모든 파일의 크기와 SHA-256이 일치하는 `검증된 압축 해제 폴더`만 최종 이름으로 확정합니다. 그 뒤 서버에 수신 완료를 알리고 임시 ZIP과 압축 해제본을 삭제합니다.
5. **ZIP 그대로 저장**을 선택하거나 ZIP이 없는 묶음이면 **iPhone에 저장** 또는 **USB에 저장**을 이어서 선택합니다. 방금 고른 파일만 승인하고 **PC 파일 수신** 화면으로 이동합니다.
6. **나중에 받기**를 누르거나 안내를 닫으면 오류로 기록하지 않고 파일을 서버에 남깁니다. 저장·검증·서버 수신 완료 처리가 끝나지 않은 파일은 앱이 다시 활성화될 때마다 다시 안내하며, 같은 활성 세션에서는 **수신 대기 N개 · 저장 위치 선택**으로 직접 다시 열 수 있습니다.
7. **iPhone에 저장**을 선택했다면 `파일 > 나의 iPhone > SimpleCamera 업무사진 전송 > 받은 파일`에 저장됩니다. 시작된 다운로드는 다른 앱을 쓰는 중에도 iOS가 이어갈 수 있습니다. 저장 완료 시 앱의 파일 목록도 갱신됩니다.
8. **USB에 저장**은 USB를 연결하고 수신 화면을 전면에 둔 채 사용합니다. USB 폴더가 없으면 선택창이 열리며, 사용할 수 없으면 **iPhone에 저장** 또는 **서버에 대기**를 선택합니다. USB 폴더를 다시 지정하면 대기했던 USB 수신을 재시도합니다.
9. 프로그레스 바, 퍼센트, 바이트, 속도, 남은 시간과 다운로드·압축 해제·USB 복사·검증 단계를 확인합니다. USB 직접 수신이 중단되면 같은 USB와 폴더로 돌아와 검증된 8MiB 경계부터 이어받습니다.

메인 화면과 **PC 파일 수신** 화면은 진행 중·저장 완료·서버/네트워크 오류를 같은 상태 카드로 표시합니다. 마지막 저장 또는 실패 결과는 앱을 다시 열어도 유지되며 새 파일이 없다고 지워지지 않습니다. 빈 확인 결과를 `USB 저장 완료 · 100%`로 표시하지 않습니다. 네트워크 확인이 실패했다고 이미 확인한 대기 파일 목록을 지우지 않습니다.

앱을 열지 않은 상태에서의 새 파일 푸시 알림과 상시 백그라운드 감시는 지원하지 않습니다. **서버에 대기**를 선택한 파일은 ACK 없이 서버에 남으며, 기본 7일 보관 기한 안에 수신해야 합니다. 손상·암호화·위험 경로 ZIP이나 저장·검증 실패도 ACK하지 않으므로 서버 원본과 안전한 재개 상태가 남고, 다음 활성화 때 다시 받을 수 있습니다.

### 나중에 iPhone 파일을 USB로 복사

1. USB를 연결하고 **PC 파일 수신** 화면에서 USB 폴더를 선택합니다.
2. **iPhone에 저장된 파일** 목록에서 보낼 파일을 선택하고 **선택 파일 USB로 복사**를 누릅니다.
3. 선택에 ZIP이 하나라도 있으면 **압축 해제해서 복사**, **ZIP 그대로 복사**, **취소** 중에서 고릅니다. 압축 해제 방식은 ZIP에만 적용되고 같은 선택에 든 일반 파일은 원본 그대로 복사됩니다. 취소하면 선택을 유지한 채 아무 파일도 복사하지 않습니다.
4. 복사가 끝날 때까지 수신 화면을 전면에 둡니다. 파일 목록 아래의 **USB 복사 상태**에서 현재 파일·퍼센트·복사 바이트를 확인합니다. 위쪽 **PC 새 파일 수신 상태**와는 별개입니다. 쓰기·닫기 오류와 파일 크기를 확인한 뒤 복사 완료로 처리하며, USB 전체 SHA 재읽기는 기본으로 실행하지 않습니다.
5. **USB 전송이 완료되었습니다. iPhone 원본을 삭제할까요?**가 나오면 **원본 유지(권장)** 또는 **iPhone 원본 삭제**를 선택합니다. 삭제는 자동으로 실행되지 않으며, 원본이 바뀌었다면 삭제하지 않습니다.
6. 실패하면 USB 복사 오류와 시스템 오류 코드가 그대로 남고, 실패한 파일의 선택도 유지됩니다. PC의 자동 수신 확인은 이 결과를 지우지 않습니다. 연결·권한·공간을 확인한 뒤 복사를 다시 누르면 됩니다. 진행 중에는 같은 복사가 중복 실행되지 않습니다.

**압축 해제해서 복사**는 iPhone에서 ZIP의 CRC 손상 검사를 하며 압축을 풀고, ZIP 이름·`ROOT`·`SD_CARD_ROOT`·`USB_ROOT` 같은 포장 폴더 없이 실제 내용물을 USB·SD카드 루트에 바로 복사합니다. ZIP 안의 실제 하위 폴더 구조는 유지합니다. 각 파일의 쓰기·닫기 및 크기 확인 후 iPhone의 임시 압축해제본을 정리합니다. **ZIP 그대로 복사**는 원본 ZIP을 일반 파일처럼 복사합니다. 어느 방식을 골라도 원본 ZIP은 복사 완료 후 확인창에서 사용자가 삭제를 선택할 때만 삭제합니다. 손상되었거나 암호화된 ZIP, USB 폴더 밖으로 빠지는 경로 또는 심볼릭 링크가 포함된 ZIP은 원본을 유지한 채 오류를 표시합니다.

추가 검증을 원하면 원본을 유지한 뒤 해당 파일을 선택하고 **선택 파일의 USB 복사본 정밀 SHA 검증**을 누릅니다. 복사 중 이미 읽은 데이터에서 만든 기록과 USB 데이터를 비교하므로 전체 USB 파일을 다시 읽는 시간은 이 버튼을 누른 경우에만 듭니다. 정밀 검증 실패 시에도 USB 복사본과 iPhone 원본은 삭제하지 않습니다. 이 검증은 0.3.23 이후 이 앱에서 복사 기록을 남긴 파일에 적용되며, 해당 USB와 복사 대상 폴더를 다시 선택해야 합니다.

`iPhone에 저장된 파일` 목록은 앱을 열 때 서버·등록·USB 폴더 확인보다 먼저 `받은 파일` 폴더에서 다시 읽습니다. 서버 연결이 끊겼거나 예전에 지정한 USB가 빠져 있어도 기존 파일은 계속 표시되므로, 새 PC 파일을 다시 받을 필요 없이 언제든 USB로 복사할 수 있습니다. iOS의 내부 요청 취소 코드 `-999`는 인터넷 장애나 수신 실패로 기록하지 않으며, 이전 버전이 잘못 저장한 `-999` 오류도 시작할 때 정리합니다.

USB 여유 공간 조회값만으로 복사를 차단하지 않습니다. 실제 저장 중 공간 부족 오류가 발생하면 실패와 시스템 오류 코드를 표시하고, 이번 복사에서 만든 불완전한 파일을 정리합니다. iPhone 원본과 USB의 기존 파일은 유지합니다.

### SD/USB의 모든 파일 삭제

1. **설정 → SD/USB 저장장치 관리**를 열고 SD/USB 폴더를 선택합니다. 카드 전체를 비우려면 하위 폴더가 아니라 카드의 최상위 폴더를 선택합니다.
2. 표시되는 **파일시스템(참고)** 정보는 확인용이며 앱이 파일시스템을 포맷하거나 변경하지 않습니다.
3. **선택한 저장장치 내용 전체 삭제**를 누르면 앱이 숨김 파일과 하위 폴더를 포함해 파일 수·폴더 수·용량을 먼저 계산합니다.
4. 확인창의 대상 폴더와 수량을 확인한 뒤 **모든 파일 삭제**를 눌러야 삭제가 시작됩니다. 확인 뒤 내용이나 저장장치가 바뀌면 삭제하지 않고 다시 확인하도록 안내합니다.

삭제 범위는 선택한 폴더 안의 내용뿐입니다. 선택한 폴더 자체와 iPhone에 저장된 원본은 유지되며 삭제 후 남은 항목을 다시 검사합니다. 이 삭제는 되돌릴 수 없습니다.

### iPhone에 저장된 파일 직접 삭제

1. **PC 파일 수신 → iPhone에 저장된 파일**에서 삭제할 파일만 선택합니다.
2. **선택 파일 삭제**를 누르고 확인창의 파일 이름과 개수를 확인합니다.
3. **삭제**를 눌러야 실제로 삭제됩니다. **취소**하면 어떤 파일도 삭제하지 않습니다.
4. 삭제 결과와 남은 파일 목록이 바로 갱신됩니다. 일부만 실패하면 실제 삭제 개수와 실패한 파일의 원인을 별도로 표시합니다.

iPhone의 선택한 원본만 삭제하며 USB·PC의 파일과 선택하지 않은 파일은 그대로 둡니다. 수신 완료 확인이 남아 있거나 선택 후 변경된 파일, 폴더·연결 파일은 삭제하지 않습니다. 삭제한 원본은 앱에서 복구할 수 없습니다. 서버에서 수신하는 파일의 SHA 검증은 유지하며, 이미 iPhone에 저장된 파일의 USB 복사는 크기 확인 후 완료하고 정밀 SHA 검증을 별도로 선택합니다.

기존 파일을 보존하려면 SideStore에서 기존 앱에 업데이트 설치하세요. 앱을 삭제한 뒤 재설치하지 마세요.

업데이트 뒤 앱이 내부 상태 파일을 읽지 못하면 손상된 메타데이터만 별도 이름으로 격리하고 다시 실행합니다. 받은 원본 파일·USB 파일·서버 대기 파일은 삭제하지 않습니다. 자동 사진 장부가 복구된 경우 과거 사진이 한꺼번에 전송되지 않도록 자동전송이 비활성화되므로 **설정 → 이 시점부터 자동 전송**을 다시 누릅니다.

받은 파일은 자동으로 열거나 실행하지 않으며 기존 파일을 덮어쓰지 않습니다. 4GiB 초과 파일은 FAT32에 저장할 수 없으므로 exFAT USB와 전원 공급형 Lightning-USB 어댑터를 권장합니다. 실제 어댑터·USB 인식과 전력 공급은 iPhone에서 확인해야 합니다.
