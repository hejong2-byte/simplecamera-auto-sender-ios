# 설치 및 자동화 설정

## 1. SideStore로 설치

1. 저장소의 QR을 아이폰 카메라로 스캔합니다.
2. SideStore가 열리면 `SimpleCamera 업무사진 전송`을 설치합니다.
3. SideStore에서 평소처럼 7일 이내에 갱신합니다.

## 2. 앱 최초 설정

앱을 열고 **설정**을 누른 뒤 화면의 1~3번을 순서대로 진행합니다.

1. **사진 전체 접근 허용**을 누르고 전체 접근을 허용합니다.
2. 기존 PC 수신기에서 사용하던 전송 인증값을 **전송 인증 설정**에 그대로 입력하고 저장합니다.
3. **이 시점부터 자동 전송**을 누릅니다. 이 버튼을 누르기 전 사진은 전송하지 않습니다.

인증값은 아이폰 Keychain에만 저장됩니다. GitHub 저장소, IPA, QR 코드에는 들어 있지 않습니다.

## 3. 개인용 자동화 한 번 만들기

1. 아이폰에서 **단축어** 앱을 엽니다.
2. 아래의 **자동화**를 누르고 새 개인용 자동화를 만듭니다.
3. **앱**을 선택합니다.
4. 앱으로 **Simple Cam**을 선택합니다.
5. 조건은 **닫힐 때**만 선택합니다.
6. 실행 동작으로 **새 SimpleCamera 사진 전송**을 검색해 추가합니다.
7. **즉시 실행**을 선택하고 실행 전 묻기는 끕니다.

이 자동화에는 `사진 찾기`, `최근 사진 가져오기`, `각 항목 반복`, `URL 콘텐츠 가져오기`를 추가하지 않습니다.

## 4. 사용

Simple Cam으로 한 장 또는 여러 장을 촬영하고 앱을 닫으면 보조 앱이 자동으로 열리고 새 SimpleCamera 사진을 모두 찾아 PC 전송 완료까지 수행합니다. 별도 버튼은 누르지 않습니다. 아이폰 기본 카메라 사진과 스크린샷은 전송하지 않습니다.

**지금 전송**과 **실패 사진 재시도**는 자동화가 실패했을 때만 쓰는 복구 기능입니다. 인증 오류가 표시되면 인증값을 다시 저장한 뒤 재시도합니다.

### 사진·스크린샷·동영상 직접 전송

1. 앱 첫 화면에서 **사진 전송**, **스크린샷 전송** 또는 **동영상 전송**을 누릅니다.
2. Apple 시스템 선택창에서 보낼 항목을 여러 개 선택합니다.
3. 완료하면 선택한 항목만 PC로 전송됩니다.

**사진 전송**에는 아이폰 기본 카메라 사진을 포함한 이미지가 표시됩니다. **스크린샷 전송**에는 스크린샷만, **동영상 전송**에는 동영상만 표시됩니다. 100MB가 넘는 동영상은 앱이 자동으로 나눠 보내며 사용자가 별도로 조작할 것은 없습니다. 파일당 최대 크기는 2GiB입니다.
