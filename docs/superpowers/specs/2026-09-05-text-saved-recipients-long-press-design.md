# iPhone 텍스트 수신코드 저장 및 기록 길게 누르기

## 목표

`텍스트 송수신` 화면에서 자주 쓰는 상대 수신코드를 이름과 함께 저장해 쉽게 구분하고 다시 사용할 수 있게 한다. 텍스트 기록은 상세 화면을 열지 않아도 목록을 길게 눌러 복사·저장·공유·삭제할 수 있게 한다.

## 수신코드 저장

- 저장 대상은 텍스트를 보낼 상대의 숫자 6자리 수신코드다. iPhone 자신의 수신코드나 PC 파일 수신코드는 변경하지 않는다.
- 최대 5개를 저장한다.
- 각 항목은 사용자가 입력한 이름과 코드로 구성하며 `행정망 PC · 709592`, `아이폰 · 123456`처럼 함께 표시한다.
- 이름은 앞뒤 공백을 제거한 뒤 비어 있지 않아야 하고, 코드는 숫자 6자리여야 한다.
- 같은 코드를 다시 저장하면 기존 항목의 이름만 바꾸고 목록 순서는 유지한다.
- 저장된 항목을 누르면 받는 코드 입력칸에 즉시 적용하고 선택 상태를 표시한다.
- 마지막으로 선택한 저장 항목은 앱을 다시 실행해도 복원한다. 사용자가 코드를 직접 편집해 저장 항목과 달라지면 선택 표시는 해제하지만 입력값은 유지한다.
- 저장된 항목은 이름 변경과 삭제를 할 수 있다. 삭제는 확인창을 거치며 텍스트 원문·송수신 기록·초안·인증정보에는 영향을 주지 않는다.

## 화면 구성

- 기존 받는 코드 입력칸과 보내기 동작은 유지한다.
- 코드 입력칸 옆에 `저장` 버튼을 두고, 유효한 코드일 때 이름 입력창을 연다. 이미 저장된 코드라면 기존 이름을 먼저 보여준다.
- 입력칸 아래에 `저장된 수신코드` 영역을 항상 표시한다. 저장 항목이 없으면 빈 상태 문구를 표시하고, 있으면 이름과 6자리 코드를 모두 볼 수 있는 행으로 표시한다.
- 현재 선택된 항목에는 체크 표시와 강조색을 사용한다.
- 저장 항목 관리 동작은 해당 행의 길게 누르기 메뉴에서 `이름 변경`, `삭제`로 제공한다.

## 기록 길게 누르기

- 기존처럼 기록 행을 짧게 누르면 상세 화면을 연다.
- 기록 행을 길게 누르면 `전체 복사`, `TXT로 저장`, `공유`, `삭제` 메뉴를 표시한다.
- `전체 복사`는 해당 기록의 전체 원문만 클립보드에 넣는다.
- `TXT로 저장`과 `공유`는 기존 상세 화면과 같은 UTF-8 원문 및 파일명 규칙을 사용한다.
- `삭제`는 기존 확인창을 표시하고, 확인 전에는 데이터를 변경하지 않는다.
- 상세 화면의 기존 복사·저장·공유·삭제 기능은 그대로 유지한다.

## 로컬 보존

- 저장 수신코드 목록과 마지막 선택은 기존 텍스트 저장 루트 아래 별도 JSON 파일에 원자적으로 저장한다.
- 기존 메시지 JSON, 삭제 표식, 작성 초안, 사진 전송 원장, PC 파일 수신 기록, 인증정보는 수정하거나 이전하지 않는다.
- 저장 파일을 읽을 수 없거나 항목 일부가 잘못된 경우 유효한 항목만 최대 5개까지 복원하고, 현재 메모리의 정상 목록을 실패한 쓰기로 덮어쓰지 않는다.

## 오류와 상태

- 잘못된 코드, 빈 이름, 5개 초과, 저장 실패를 구분해 사용자에게 표시한다.
- 저장·이름 변경·삭제 성공은 짧은 완료 문구로 알린다.
- 수신코드 저장 오류는 텍스트 전송·수신 감시를 중단시키지 않는다.

## 검증 기준

- 처음 저장, 최대 5개, 6번째 거부, 같은 코드 이름 갱신, 선택 적용, 직접 편집 시 선택 해제, 마지막 선택 재실행 복원을 단위 테스트한다.
- 잘못된 JSON, 잘못된 이름·코드, 중복 항목, 저장 실패 시 기존 목록 보존을 테스트한다.
- UI 테스트에서 이름과 코드의 동시 표시, 선택 적용, 이름 변경, 확인 후 삭제를 검증한다.
- UI 테스트에서 기록을 짧게 누르면 상세 화면, 길게 누르면 네 가지 작업 메뉴가 표시되고 각 작업이 올바른 기록을 대상으로 하는지 검증한다.
- 기존 텍스트 초안·송수신·재시도·읽음·삭제 테스트와 전체 iOS 테스트를 다시 실행한다.
- 새 IPA의 버전·빌드·번들 ID·무결성과 SideStore 설치 QR 대상을 검증한다.

## 제외 범위

- 여러 상대에게 동시에 텍스트 보내기
- 저장 수신코드의 서버 동기화 또는 다른 기기와 공유
- 상대 기기 종류의 자동 판별
- 기존 Windows 저장 수신코드 파일 가져오기
