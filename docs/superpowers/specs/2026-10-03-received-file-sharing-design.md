# 받은 사진·PDF 공유

사용자는 2026-10-03 아이폰 앱 적용을 선택하고 아래 설계에 `진행`으로 승인했다.

## 범위와 동작

- PC 파일 수신 화면의 iPhone 저장 파일 목록에서 사진·PDF의 `열기` 옆에 `공유` 버튼을 표시한다.
- 버튼을 누르면 iOS 공유창에 실제 로컬 파일 URL을 전달한다. 사용자가 카카오톡과 대화방을 선택하고 직접 전송한다.
- 카카오 SDK, 링크 업로드, 채팅 자동 발송, Windows 앱 변경은 하지 않는다.
- 취소 또는 공유 후 원본과 파일 선택 상태를 유지한다. 시스템 공유 완료를 상대방 수신 완료라고 표시하지 않는다.
- 저장 목록의 완성된 파일만 사용한다. 공유 직전 기존 카탈로그의 경로·파일 상태 검사를 재사용한다. 없거나 바뀐 파일은 별도 공유 오류로 알리고 목록을 갱신한다.
- 공유창과 새 파일 수신 안내가 겹치지 않게 한다. 공유 중 원본 삭제를 막는다. 미리보기·삭제 확인·전송 등 진행 중인 작업과 공유 시작을 중복하지 않는다.
- 사진·PDF 이외의 파일 UI와 기존 수신·USB 기능은 바꾸지 않는다.

## 검증과 배포

실제 임시 파일을 사용하는 모델 테스트로 형식 제한, 변경·삭제된 원본, 선택 보존, 취소, 오류 분리, 삭제 및 수신과의 충돌 방지를 검사한다. 시뮬레이터 UI 테스트로 사진·PDF 버튼, 시스템 공유창, 취소 후 파일 보존을 확인한다. 카카오톡이 없는 시뮬레이터에서 실제 대화방 전송 완료를 주장하지 않는다.

iOS 버전만 0.3.45(56)에서 0.3.46(57)으로 올린다. 전체 iOS 테스트와 IPA 설치 계약 검사를 통과한 뒤 기존 SideStore 배포 절차로 설치 QR을 제공한다.

공식 근거: https://developers.kakao.com/docs/ko/kakaotalk-share/common 의 `OS 공유 사용` (2026-10-03 확인).
