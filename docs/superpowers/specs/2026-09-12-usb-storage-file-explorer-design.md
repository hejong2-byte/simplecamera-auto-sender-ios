# SD/USB 저장장치 파일 탐색 및 PC 전송 설계

## 목표

`설정 → SD/USB 저장장치 관리`에서 현재 선택한 USB 메모리 또는 SD 카드의 내용을 앱 안에서 탐색하고, 파일을 하나 또는 여러 개 선택해 저장된 PC 수신코드로 전송한다.

## 확정 범위

- 저장장치 관리 화면에 `파일 탐색기`를 추가한다.
- 선택한 저장장치의 최상위 폴더부터 하위 폴더까지 단계별로 이동할 수 있다.
- 폴더는 탐색 대상으로만 사용하고 전송 대상으로 선택하지 않는다.
- 일반 파일만 단일·다중 선택할 수 있다.
- 현재 선택된 파일 개수와 합계 용량을 표시한다.
- 숨김 파일도 저장장치에 실제로 존재하는 일반 파일이면 표시한다. 앱이 만든 전송 중간파일은 선택 대상에서 제외한다.
- 전송할 PC는 기존에 저장된 이름과 숫자 6자리 수신코드 목록에서 선택한다.
- 저장된 PC 수신코드가 없으면 텍스트 송수신 또는 기존 파일 전송 화면에서 먼저 저장하도록 안내한다.
- 선택 파일은 기존 `ManualMediaTransferService.enqueueFiles` 흐름으로 넘겨 앱 내부 전송 준비 공간에 복사한 후 기존 백그라운드 업로드 엔진으로 전송한다.
- 전송 성공, 실패, 취소와 관계없이 SD/USB 원본은 수정하거나 삭제하지 않는다.

## 사용자 흐름

1. 사용자가 `설정 → SD/USB 저장장치 관리`를 연다.
2. 저장장치 폴더가 선택되어 있지 않으면 기존 `USB 폴더 선택`을 사용한다.
3. `파일 탐색기` 카드에서 현재 폴더의 폴더와 파일 목록을 확인한다.
4. 폴더 행을 누르면 그 폴더로 이동하고, 상위 경로 버튼으로 돌아간다.
5. 파일 행 또는 선택 원을 눌러 하나 이상의 파일을 선택한다.
6. `PC로 전송`을 누른다.
7. 저장된 PC 목록에서 이름과 수신코드를 확인하고 목적지를 선택한다.
8. 선택 파일을 앱 내부 전송 준비 공간으로 복사하며 진행 상태를 표시한다.
9. 준비가 완료된 파일은 기존 백그라운드 파일 전송 대기열에 등록된다.
10. 이후 진행률과 결과는 기존 메인 화면의 파일 전송 상태에서 확인한다.

## 화면 구성

기존 저장 위치 카드와 저장장치 내용 삭제 카드 사이에 파일 탐색기 카드를 배치한다.

```text
┌ 파일 탐색기 ───────────────────┐
│ 저장장치 / MAP / KOREA          │
│ [상위 폴더]        [새로 고침] │
│ 📁 하위 폴더                    │
│ ○ 파일1.zip        8.1 GB      │
│ ● 파일2.jpg        3.2 MB      │
│ ○ 파일3.txt        12 KB       │
│ 선택 1개 · 3.2 MB              │
│ [선택 해제]      [PC로 전송]   │
└─────────────────────────────────┘
```

- 폴더를 먼저, 파일을 다음에 표시하고 각 그룹 안에서는 이름 오름차순으로 정렬한다.
- 파일명은 여러 줄로 표시할 수 있으며 크기와 수정 시각을 보조 정보로 표시한다.
- `PC로 전송`은 선택 파일이 있고 저장장치를 읽을 수 있으며 다른 파일 준비 작업이 진행 중이지 않을 때만 활성화한다.
- 대상 선택 화면은 기존 `FileTransferRecipientPicker`와 같은 저장 수신코드 데이터를 사용하되, 새 코드 입력 없이 저장된 PC를 고르는 데 집중한다.

## 구성 요소

### `USBStorageFileExplorer`

- 보안 범위가 적용된 저장장치 루트 안에서만 폴더 내용을 읽는다.
- 현재 상대 경로를 관리하고 루트 밖으로 이동하는 경로 및 심볼릭 링크를 거부한다.
- 파일 유형, 크기, 수정 시각을 읽어 화면용 항목으로 변환한다.
- 저장장치가 분리되거나 북마크가 만료되면 구체적인 오류를 반환한다.

### `USBStorageFileExplorerViewModel`

- 현재 경로, 목록, 선택 파일 식별자, 합계 용량, 로딩·오류 상태를 소유한다.
- 폴더 이동, 상위 이동, 새로 고침, 파일 선택·해제를 처리한다.
- 새로 고침 후 사라졌거나 일반 파일이 아니게 된 항목은 선택에서 제거한다.
- 전송 요청 시 현재 선택 파일을 다시 검증하고 기존 파일 전송 함수로 넘긴다.

### `USBStorageFileExplorerView`

- 기존 저장장치 관리 화면의 카드 스타일과 cyan 강조색을 유지한다.
- 폴더 이동과 파일 선택을 명확히 구분한다.
- 저장된 PC 선택 시 이름과 코드가 함께 보이도록 한다.

### 기존 구성 요소 재사용

- `USBBookmarkStore`: 선택 저장장치 루트 복원
- `TextSavedRecipientStore`: 저장된 PC 이름·수신코드 읽기
- `ManualMediaTransferService.enqueueFiles`: 파일 준비와 업로드 대기열 등록
- `ManualDocumentSource`: 보안 범위 파일을 앱 내부로 안전하게 복사
- `ManualBackgroundTransferEngine`: 백그라운드 분할 전송과 재시도

## 데이터 및 권한 처리

- 디렉터리 열람과 전송 준비 동안 보안 범위 접근 권한을 유지한다.
- 화면에는 절대 경로 대신 저장장치 이름과 상대 경로만 표시한다.
- 선택 상태는 현재 화면 세션에서만 유지하며 앱 재실행 후 자동 복원하지 않는다.
- 외부 저장장치 파일의 북마크를 파일별로 새로 저장하지 않는다.
- 전송 준비 시 기존 `ManualDocumentSource`가 각 원본을 앱 내부 사본으로 만든다. 이후 저장장치가 분리되어도 준비가 끝난 파일의 서버 전송은 계속될 수 있다.
- 저장장치 원본은 읽기 전용으로 취급한다. 탐색기 전송 기능은 생성, 이름 변경, 이동, 삭제를 수행하지 않는다.

## 오류 처리

- 저장장치 미선택: `SD/USB 폴더를 먼저 선택해 주세요.`
- 저장장치 분리 또는 접근 실패: `SD/USB 저장장치를 다시 연결하고 폴더를 선택해 주세요.`
- 북마크 만료: `저장장치 폴더 권한이 만료되었습니다. 다시 선택해 주세요.`
- 파일이 준비 전에 변경되거나 사라짐: 해당 파일만 실패 처리하고 다른 선택 파일은 계속 준비한다.
- 폴더·심볼릭 링크 선택 시도: 전송 대상으로 허용하지 않는다.
- 저장 수신코드 없음: `저장된 PC 수신코드가 없습니다. 파일 전송에서 PC를 먼저 저장해 주세요.`
- 저장장치가 매우 느릴 때: 준비 진행률과 현재 파일명을 기존 수동 전송 상태에 표시한다.

## 테스트 및 성공 기준

1. 임시 저장장치 트리에서 폴더 우선·이름순 목록이 생성된다.
2. 루트와 하위 폴더 이동은 가능하고 루트 밖 경로와 심볼릭 링크는 거부된다.
3. 파일 단일 선택과 다중 선택, 선택 해제, 합계 용량 계산이 정확하다.
4. 새로 고침 후 사라진 파일은 선택에서 제거된다.
5. 저장된 수신코드가 대상 목록에 이름·코드로 표시된다.
6. 선택 파일과 수신코드가 기존 `enqueueFiles` 호출로 정확히 전달된다.
7. 저장 수신코드가 없거나 저장장치가 분리된 경우 전송이 시작되지 않고 안내가 표시된다.
8. 기존 SD/USB 전체 삭제, ZIP 압축 해제·복사, 일반 파일 전송 회귀 테스트가 계속 통과한다.
9. iPhone 14 Pro 크기의 시뮬레이터에서 파일명, 선택 상태, 전송 버튼이 잘리지 않는다.

## 제외 범위

- 폴더 자체를 선택해 재귀 전송하는 기능
- 저장장치 파일의 삭제, 이름 변경, 이동 기능 추가
- 저장장치 안에서 ZIP을 풀거나 다시 압축하는 기능
- 새로운 수신코드 저장 형식 또는 별도 전송 프로토콜
- 저장장치 탐색 위치와 파일 선택의 앱 재실행 후 복원
