# 모든 새 사진 자동전송 설계 (폐기됨)

> 이 설계는 사용자의 최종 요구사항과 달라 폐기됐다. 구현 기준은 `2026-08-22-simple-cam-resolution-origin-filter-design.md`이며, Simple Cam 사진만 전송해야 한다.

## 목표

사용자가 전송 시작 버튼을 누른 시점 이후 iPhone 사진 보관함에 추가되는 모든 이미지를 기존 업무사진 중계 서버로 전송한다. 촬영 앱이나 이미지 종류를 구분하지 않는다. 일반 카메라 사진, Simple Cam 사진, 스크린샷, 다운로드하거나 저장한 이미지가 모두 대상이다.

기존 사진 보관함의 이미지는 전송하지 않으며, 같은 이미지는 한 번만 전송한다.

단축어 개인용 자동화에 의존하지 않는 독립 iPhone 앱으로 동작한다.

## 선택한 방식

기존의 TIFF `Software` 메타데이터 판별을 완전히 제거한다. PhotoKit에서 시작 시각 이후 생성된 이미지 자산을 찾고, 전송 기록에 없는 자산을 모두 업로드 대기열에 넣는다.

다음 대안은 사용하지 않는다.

- Simple Cam 메타데이터 유지: 앱 버전과 저장 방식에 따라 값이 달라져 실제 사진을 누락할 수 있다.
- 상시 실행을 가장한 위치·오디오 백그라운드 사용: 기능 목적과 맞지 않고 배터리 소모가 크며 iOS가 계속 실행을 보장하지 않는다.
- 기존 사진함 전체 스캔: 사용자가 원하지 않는 과거 사진까지 대량 전송될 수 있다.

## 시작 기준과 업그레이드

새 버전은 기존 Simple Cam 전용 감시 기준을 그대로 사용하지 않는다. 첫 실행에서 전체 사진 모드가 아직 활성화되지 않았음을 표시하고, 사용자가 `지금부터 모든 새 사진 전송`을 누른 시각을 새 기준으로 저장한다.

이전 버전의 사진 판별 기록은 새 모드의 전송 대상으로 사용하지 않는다. 따라서 버튼을 누르기 전 사진은 전송되지 않는다.

## 전송 흐름

1. 앱 시작, 포그라운드 복귀, 사진 보관함 변경 알림 또는 iOS가 허용한 백그라운드 갱신 때 검색을 실행한다.
2. PhotoKit에서 시작 시각 이후 사진 보관함에 추가된 모든 이미지 자산을 가져온다.
3. 이미 전송 대기, 전송 완료 또는 처리 중인 자산은 건너뛴다.
4. 원본 이미지 파일을 내보내 기존 중계 서버 업로드 대기열에 넣는다.
5. 결과에 `발견`, `전송 시작`, `실패` 수를 표시해 사진 검색과 서버 전송 문제를 구분할 수 있게 한다.

사진 저장 완료가 늦는 경우를 위해 한 번의 실행 안에서 짧게 재검색한다. 원본을 아직 읽지 못한 자산은 완료 처리하지 않고 다음 실행에서 다시 시도한다.

## 독립 앱 실행 방식

앱은 실행 중 `PHPhotoLibraryChangeObserver`로 사진 보관함 변경을 감지하고 즉시 검색한다. 앱을 다시 열거나 포그라운드로 돌아올 때마다 누락된 새 사진을 자동 검색한다. 전송 대기열은 백그라운드 URL 세션을 사용해 앱이 잠시 중단돼도 iOS가 허용하는 동안 업로드를 이어간다.

앱은 시스템 백그라운드 갱신 작업도 예약한다. 다만 iOS가 실행 시각을 결정하므로 앱이 완전히 종료되거나 오래 중단된 동안 촬영된 사진의 즉시 전송은 보장하지 않는다. 그런 사진은 다음 백그라운드 실행 또는 앱을 다시 열었을 때 자동 전송된다.

화면에는 `감시 중`, `백그라운드 대기`, `사진 접근 필요` 상태와 마지막 검색·전송 결과를 명확히 표시한다. `지금 확인` 버튼은 필요할 때 즉시 누락분을 검색한다. 단축어 설정 안내와 App Intent는 제거한다.

## 오류 처리

- 사진 접근이 전체 허용이 아니면 전송하지 않고 명확한 안내를 표시한다.
- 인증값이 없거나 거부되면 사진 기록을 완료 처리하지 않는다.
- 원본 읽기 또는 네트워크 전송 실패 사진은 실패 상태로 남겨 재시도할 수 있게 한다.
- 서버에 접수된 사진만 전송 완료로 기록한다.

## 검증 기준

- 시작 버튼 이전 사진은 전송되지 않는다.
- 시작 버튼 이후 일반 카메라, Simple Cam, 스크린샷 이미지가 각각 검색된다.
- 메타데이터가 없거나 다른 값이어도 전송된다.
- 동일 사진을 대상으로 검색을 여러 번 실행해도 한 번만 업로드된다.
- 원본이 늦게 준비되거나 네트워크가 실패한 사진은 다음 실행에서 재시도된다.
- 검색 결과가 발견 수, 전송 시작 수, 실패 수를 구분해 표시한다.
- 앱 실행 중 새 이미지가 추가되면 별도 버튼이나 단축어 없이 검색이 시작된다.
- 앱을 중단한 동안 추가된 이미지는 앱을 다시 열면 자동으로 검색된다.
- 단축어 개인용 자동화를 설정하지 않아도 모든 기능이 동작한다.
- 기존 PC 수신기와 인증 형식은 변경하지 않는다.
