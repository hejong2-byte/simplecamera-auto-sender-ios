# 스크린샷 자동 전송 설계

## 목표

기존 `Simple Cam이 닫힐 때` 개인용 자동화를 그대로 사용하면서, 자동 전송 시작 시점 이후 생성된 Simple Cam 사진과 iPhone 스크린샷을 다음 자동화 실행에서 모두 PC로 전송한다. 사용자는 스크린샷 전송을 위해 새 버튼을 누르거나 별도 자동화를 만들지 않는다.

## 확정된 동작

1. 앱의 기존 자동 전송 기준시각보다 늦게 생성된 이미지 중 장부에 성공 기록이 없는 항목을 검사한다.
2. Simple Cam 사진은 기존 규칙인 `6048×8064` 또는 `8064×6048` 해상도이면서 TIFF 카메라 모델과 EXIF 렌즈 모델에 `iPhone`이 없는 경우에만 허용한다.
3. 스크린샷은 PhotoKit의 `PHAssetMediaSubtype.photoScreenshot` 표식이 있는 경우에만 허용한다.
4. 스크린샷의 해상도, 파일명, 카메라 메타데이터는 판별에 사용하지 않는다.
5. 일반 iPhone 카메라 사진, 인터넷에서 저장한 이미지와 다른 앱이 만든 일반 이미지는 계속 제외한다.
6. 스크린샷을 찍는 것만으로 앱을 깨우지는 않는다. 그다음 `Simple Cam이 닫힐 때` 자동화가 실행되면 그동안 쌓인 미전송 스크린샷을 개수 제한 없이 오래된 순서부터 처리한다.
7. HTTP 성공이 확인된 항목은 기존 장부에 완료로 기록하여 다시 보내지 않는다.

## 구조

### 후보 출처 표식

`PhotoCandidate`에 `isScreenshot: Bool`을 추가한다. `PhotoKitAssetSource`가 `PHAsset`을 후보로 변환할 때 `asset.mediaSubtypes.contains(.photoScreenshot)` 결과를 기록한다. 스크린샷 스마트 앨범을 별도로 조회하거나 두 검색 결과를 병합하지 않는다.

후보의 생성시각이 자동 전송 기준시각과 같거나 이전이면 처리하지 않는다. PhotoKit 저장 지연을 위한 기존 조회 여유 구간을 유지하더라도 서비스 단계에서 이 기준을 다시 적용하여 기준시각 이전 스크린샷이 섞이지 않게 한다.

### 대상 판별

전송 서비스는 원본을 임시 파일로 내보낸 뒤 다음 논리로 대상을 결정한다.

- `candidate.isScreenshot == true`: 스크린샷으로 허용한다.
- 그 외: 기존 `SimpleCameraMetadataMatcher`를 통과한 경우에만 Simple Cam 사진으로 허용한다.

스크린샷 표식이 없는 파일은 기존 해상도·`iPhone` 판별을 우회할 수 없다. 기존 메타데이터 판별기는 변경하지 않는다.

### 기존 자동화와 장부

`SendNewSimpleCameraPhotosIntent`의 타입과 기존 자동화 식별자를 유지한다. 따라서 설치 후 단축어 자동화를 다시 만들 필요가 없다. 같은 `UploadLedger`와 PhotoKit 로컬 식별자를 사용하므로 Simple Cam 사진과 스크린샷 모두 동일한 중복방지·실패 재시도 규칙을 적용받는다.

## 오류 처리와 데이터 안전

- 스크린샷 원본을 읽지 못하거나 업로드가 실패하면 성공으로 기록하지 않고 다음 Simple Cam 종료 때 다시 시도한다.
- 한 항목의 실패가 다른 Simple Cam 사진이나 스크린샷 전송을 막지 않는다.
- 서버가 HTTP 성공을 반환한 항목만 완료 수에 포함한다.
- 사진 내용, 인증값과 위치 정보는 로그에 기록하지 않는다.
- 기존 기준시각, 장부와 Keychain은 초기화하거나 형식을 변경하지 않는다.
- 일반 사진을 허용하는 포괄 규칙은 추가하지 않는다. 스크린샷 우회 조건은 PhotoKit의 전용 표식 하나로 제한한다.

## 화면과 안내 문구

앱의 소개, 자동 전송 시작 안내, 자동화 안내와 설치 문서를 `Simple Cam 사진 및 스크린샷` 대상으로 수정한다. 기존 `지금 전송`과 `실패 사진 재시도`는 오류 복구용으로 유지한다. 기존 자동화 동작의 타입과 연결은 유지한다.

## 시험 기준

자동 시험은 다음을 검증한다.

- PhotoKit의 `.photoScreenshot` 비트가 후보의 `isScreenshot` 값으로 보존된다.
- 스크린샷 후보는 해상도·카메라 메타데이터 판별 결과와 무관하게 업로드된다.
- 스크린샷 표식이 없는 일반 사진은 기존 Simple Cam 판별을 통과하지 못하면 업로드되지 않는다.
- 기존 Simple Cam 가로·세로 해상도와 `iPhone` 제외 시험이 그대로 통과한다.
- 기준시각 이전 또는 같은 시각의 스크린샷은 전송하지 않는다.
- 여러 장의 미전송 스크린샷을 개수 제한 없이 처리한다.
- 성공한 스크린샷은 다음 실행에서 중복 전송하지 않는다.
- 실패한 스크린샷은 다음 실행에서 다시 시도한다.
- Simple Cam 사진과 스크린샷이 함께 발견되어도 각각 한 번씩 전송한다.

기기 시험 완료 조건은 다음과 같다.

1. 스크린샷 여러 장을 찍고 Simple Cam을 열었다 닫으면 별도 버튼 없이 모든 새 스크린샷이 PC에 도착한다.
2. 같은 구간의 Simple Cam 사진과 스크린샷이 함께 도착한다.
3. 일반 카메라 사진과 저장 이미지는 도착하지 않는다.
4. 같은 스크린샷이 다음 자동화에서 다시 도착하지 않는다.

## 배포 범위

앱 버전은 `0.1.7`로 올리고 번들 식별자와 Keychain 식별자는 유지한다. 소스와 자동 시험, 설치 안내를 먼저 완성한다. GitHub Release 게시와 SideStore 최신 IPA 교체는 별도 배포 단계에서 수행한다.
